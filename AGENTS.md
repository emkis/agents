# agents
The user's personal setup for AI coding agents, built specifically for Claude Code. It exists so the user stops repeating the same rules and corrections to agents, session after session.

## Layout
- **`skills/`** agent skills.
- **`hooks/`** agent hooks.
- **`home/`** the user's own config, laid out like their home directory and linked into it with GNU Stow. Not meant for reuse by other people.
